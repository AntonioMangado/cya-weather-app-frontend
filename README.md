# CyA Weather App — Frontend

React + TypeScript app built with Vite. Talks to the [backend](../backend) to display current weather and a 3-day forecast for a given city.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm test` — run the test suite (Vitest)
- `npm run lint` — run ESLint
- `npm run format` — run Prettier

## Project conventions

- Path alias `@/` maps to `src/`.
- All CSS lives under `src/styles/` — no styles co-located with components.
